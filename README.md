One Line of Earned Pride — a program that writes one original line (137 characters) to `/output/entry.txt`: an apprentice barista's eleventh rosetta finally lands without a wobble, and her regular answers with a single nod. A quiet, earned moment of pride: the effort is felt in eleven failed pours, the landing is the pour itself, and the pride arrives at the last word.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (set `OUTPUT_DIR` to override the output directory). Deterministic: no input, no network, no randomness, no clock — the same bytes on every run.
